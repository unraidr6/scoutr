# Security Policy

## Reporting Security Issues

To report a security issue, please use the GitHub Security Advisory ["Report a Vulnerability"](../../security/advisories/new) tab.

**Please do not report security vulnerabilities through public GitHub issues.**

This is a personal project, so responses are on a best-effort basis.

## What to Include in Your Report

To help in understanding and resolving the issue, please include as much of the following as possible:

- Full paths of source file(s) related to the issue
- The location of the affected source code (tag/branch/commit or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue

## Third-Party Dependencies

If you discover a security vulnerability in a third-party dependency, please report it directly to the maintainers of that project.
